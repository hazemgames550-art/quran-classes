# موقع حجز دروس تحفيظ القرآن

## النشر (زي المشاريع اللي فاتت: GitHub + Cloudflare)
1. ارفع محتوى المجلد ده كله على مستودع GitHub جديد.
2. في Cloudflare: Workers & Pages → Create → Import a repository → اختار المستودع.
   (ملف wrangler.toml فيه كل الإعدادات، والـ Durable Object بيتعمل لوحده.)
3. بعد ما يخلص النشر افتح `رابط-الموقع/admin` **فورًا** واختار كلمة السر (أول واحد يفتح الصفحة هو اللي بيحدد كلمة السر).
4. ادخل الإعدادات: السعر، أرقام انستا باي وفودافون كاش، رقم الواتساب، الاسم. وبعدين تبويب المواعيد.
5. فعّل "فتح الحجز للناس".

## ملاحظات
- الدخول للحصة: الموقع بيعمل غرفة Jitsi سرية لكل حجز (meet.jit.si). لو Jitsi طلب منك تسجل دخول علشان تبدأ الغرفة، حط رابط Google Meet ثابت في الإعدادات (رابط اجتماع ثابت).
- إيصالات الدفع بتتخزن جوه قاعدة بيانات الموقع وبتظهر لك بس في لوحة التحكم.
